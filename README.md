# text-rpg-gm

一个可让 AI Agent 直接加载运行的中文文本 RPG Skill：AI 作为 GM（游戏主持人），为玩家运行《剑火纪元 · 西方幻想人生模拟器》。

## 结构

```
text-rpg-gm/
├── SKILL.md                    # GM 协议：游戏怎么运行（总纲、建局、节奏、判定、输出格式、元指令等）
└── references/
    └── world-setting.md        # 世界设定集：世界是什么（七纪元历史、九族、五道法统、势力、暗线、建局表单）
```

两份文档分工明确：涉及**世界事实**以设定集为准，涉及**运行机制**以协议为准；内容安全高于两者。

## 使用方法

把整个目录作为 Skill 安装到支持 Agent Skills 规范的客户端（如 Claude、Qoder），或直接将两份文档作为系统提示词注入。

安装后对 AI 说任意开局指令（如"开一局""来玩文字RPG"），它会先读取设定集，然后输出《剑火纪元》建局表单：

- **快速开局**：只填第一层核心项（时代 / 种族 / 出生身份 / 姓名等），或直接回复"随机"由 GM 代抽
- **完整开局**：继续填第二层经历细化（童年、擅长、秘密、超凡之缘……）
- 表单中 **★** = 附带世界内代价或麻烦，**◆** = 附带额外限制——这是世界"明码标价"原则的一部分

游戏中常用元指令：

| 指令 | 功能 |
|---|---|
| `/状态` | 查看角色面板（按当前层级逐步展开） |
| `/月报` | 月度世界动态（演化八线推进） |
| `/存档` `/续局` | 输出 / 载入固定结构存档 |
| `/跳过` `/展开` `/重述` `/暂停` | 快进 / 细写 / 换种写法 / 讨论规则 |

## 设计要点

- **不代替玩家**：玩家的输入是意图声明，GM 展开过程与世界反应，但决定权始终在玩家
- **世界有惯性**：身份阻力、余波、延迟后果、不等玩家推进的势力计划
- **明码标价**：魔法、神术、机缘、政治皆有代价；裁定不默认偏向成功，风险前置呈现
- **爽感是合法需求**：主角光环有底线（不改因果、不降敌人智力），底线之上积极铺垫兑现路径
- **GM 内档**：设定集标注【GM 内档】的暗线内容对玩家封锁，按解锁途径逐步揭示
