# 卷一 · 世界基本规则与地理框架 (World Rules & Geography)

> 旧帝国的剑已折断，新秩序的火尚未点燃——这是一个所有道路都还没被封死的时代。

---

## 一、世界七律

| 律 | 内容 | 执行原则 |
|---|---|---|
| **恒动** | 世界在玩家不在场时也持续变化 | 势力推进计划，大事件不因玩家离场而暂停。 |
| **稀缺** | 一切资源有成本；重复做低难度的事，收益递减 | 拒绝刷怪刷钱式无脑积累，消耗是绝对的。 |
| **代价** | 魔法、神术、机缘、政治全部明码标价 | 玩家没有默认的传奇血统或开局神器，所有力量皆有账单。 |
| **凡识** | 开局认知受身份限定；高层知识必须付出代价 | 严禁上帝视角，凡人身份不可知晓神启或涉密真相。 |
| **因果** | 因果链长期有效；改革必损既得利益者，并招来反扑 | 任何重大改动必遭反弹，余波持续追讨。 |
| **死亡** | 死亡是真实的；NPC 不因玩家喜欢而复活 | 生死不可逆，NPC 与重要人物死亡即定局。 |
| **惯性** | 旧战争、旧法统、旧仇恨持续塑造当下 | 历史的重量压在每一个角色身上。 |

## 二、硬约束（不可违反）

1. **法术不可无限叠加**：多重法术相互干扰，甚至引发魔力暴走。
2. **治疗不可无限复活**：死者复生属于世界绝对禁忌，强行逆转必遭法则绞杀。
3. **时间不可无限回溯**：时间没有倒车，一切选择产生不可逆的涟漪。
4. **空间魔法不可无限复制资源**：物质守恒，虚空不能无中生有。

---

## 三、魔潮（崩渊纪的遗产）

**魔潮是深渊魔力沿裂隙向物质界的周期性渗透**——如潮汐，涨落无常。
- **上涌时**：裂隙周边的生灵与土地被浸染（畸变体、魔潮残区皆由此而来），术法施展会失控加剧，动物先行逃离。
- **由弱到强的物理征兆**：井水发苦 → 铁器夜鸣 → 动物迁徙 → 畸花绽放 → 天空变色。
- **退去后**：留下魔潮残区，土地百年生机断绝。教会至今保有崩渊纪驱潮的仪式残卷，这是其统治合法性与政治资本的核心来源之一。

## 四、五层认知门槛（决定开局知晓边界）

| 层级 | 涵盖范围 | 开局认知原则 |
|---|---|---|
| **凡俗层** | 村庄、城镇、商路、港口 | 人尽皆知，常识范畴。 |
| **文明层** | 王国、教会、学院、商会 | 人尽皆知，了解表面架构。 |
| **超凡层** | 法师塔、神殿秘辛、公会高阶、地下城 | 至少听说过，知晓风险与流言。 |
| **异界层** | 精灵领域、矮人深王宫、龙巢、深渊、浮空城 | 知其名，不知其里，凡人极难触碰。 |
| **诸界层** | 物质界、神国、虚空、原初之海、梦境 | 极少数涉密者与传奇人物方能接触。 |

*注：五层管“知道什么”，垂直三界管“人在哪里”，两套体系独立。稳定进出高层级地点必有代价，绝无廉价往返。*

## 五、垂直三界

- **苍穹层**：
  - 浮空城三种下场：
    1. **坠落者**：陨城遗址，是地面上最凶险的古代地下城；
    2. **沉眠者**：云端漂行的“暗城”，与世隔绝；
    3. **存续者**：垄断古代技艺，但粮食依赖地面供应——永远的致命软肋。
  - *认知例外*：设有天港且与地面保持稳定粮食贸易的存续者浮空城，对常来贸易者与天港居民视同超凡层认知；其余浮空城一律属异界层。
- **地表层**：凡人世界主舞台。
  - 五种魔法地貌：禁魔区、魔泉区、元素异变区、时滞带、龙脉交汇处——地貌本身就是历史遗迹。
  - *时滞带边界*：带内时间流速快慢不均，但**绝对不可回溯**——走出时滞带的人没有变年轻的，只有衰老或维持原状者。
- **地底层**：
  - **浅窟**：矿道、矮人前哨、地下走私商路；
  - **地底世界**：无日世界，拥有独立种族与城邦文明，相当于另一片大陆；
  - **渊喉**：深渊裂口，越深入时间与空间异变越剧烈。
