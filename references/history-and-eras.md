# 卷二 · 历史、时代与演化八线 (History, Eras & Evolution Tracks)

---

## 一、七纪元历史（大陆通行史观）

| 纪元 | 核心事件 | 当代遗存与历史回响 |
|---|---|---|
| **神启纪** | 诸神降临，与凡人立下圣约 | 神殿体系、圣约法统、神血后裔遗族 |
| **古族纪** | 精灵、矮人先民鼎盛，主宰大陆 | 巨型古代遗迹、失传秘银锻造、种族世仇 |
| **辉法纪** | 魔法文明极度繁荣，因狂妄傲慢自毁 | 魔法荒原、禁断秘术残卷、地下城与浮空城成因 |
| **列王纪** | 人类崛起，诸国格局最终奠定 | 现行国界、贵族血统谱系与王朝正统 |
| **崩渊纪** | 第一次大魔灾爆发，深渊裂隙贯穿物质界 | 魔潮残区、畸变生物、教会因驱潮救世而登顶 |
| **帝国纪** | 帝国短暂实现全大陆统一后迅速分裂崩解 | 帝国金币仍为通用贸易硬通货、旧行省边界 |
| **剑火纪** | 旧秩序崩解，新秩序尚未成形（当代主舞台） | 处处是机会，诸雄割据，暗流汹涌，余烬未熄 |

## 二、时代 × 世界状态对照（建局锚点）

开局选择不同时代时，GM 严格按照下表定调：

| 时代 | 对应历史锚点 | 世界状态定调 | 主要戏剧张力 |
|---|---|---|---|
| **黄金王国时代** | 列王纪盛世 | 王权强盛，教会辅政，超凡力量受严格登记管束；冒险者公会初露锋芒 | 王位继承之争、旧贵族与新兴商会的权力换手 |
| **魔法繁荣时代** | 辉法纪中期 | 学院与法师塔鼎盛，魔法渗透生活日常；浮空城高悬天空 | 魔法傲慢在积蓄，繁荣顶点即崩溃前夜（埋伏自毁远因） |
| **群雄割据时代** | 帝国纪崩溃后 | 帝国法统荡然无存，佣兵团、僭主领主与城邦联盟并立；帝国金币为硬通货 | 谁能重聚法统；夹缝中小势力的残酷求生 |
| **第二次大魔灾前夕** | 剑火纪·暗流期 | 表面太平，但魔潮征兆渐密（畸变目击、渊喉怪响、巫者通灵躁动） | 知情高层的隐瞒备战 vs 无知平民的日常求生 |
| **魔族入侵时代** | 崩渊纪当代重演 | 魔界内战败者出走，大军压境物质界；三国临时同盟各怀鬼胎 | 前线铁血抵抗 vs 境内对魔族的清洗猜忌与内部背叛 |
| **战后重建时代** | 大战后的剑火纪 | 废墟、瘟疫横行、孤儿流民遍地；魔晶枯竭暴涨 | 重建与弱肉强食、旧账清算、“战争真的结束了吗” |

## 三、世界奇观

每处奇观均有住民、政治与高昂代价，绝非单纯背景板：
- **世界树残枝**：刺穿云霄的石化巨木，无人知晓树的本源是否依然存活。
- **沉没帝都**：半淹于内海的古帝国旧都，水下溺亡者面容如生，传说保留着帝国国库。
- **玻璃之漠**：上古法战将百万军团连同广袤沙漠熔融为坚硬黑绿玻璃的死地。
- **逆瀑**：自地面径直倒流向天穹的魔力河流，直通某座神秘的未知浮空城。
- **永冬王座**：不腐之王静坐王座——自他端坐的那一夜起，极北的暴风雪至今未停。
- **星坠之环**：天外异物撞击形成的山脉，环心金属每逢子夜发出低沉的共振歌声。
- **万门之城**：围绕上千座来历不明、通往不同位面的古老石门建立的法外自由港。
- **哀嚎裂谷**：魔灾撕裂大地的永久创口，深处终年回荡着深渊气流的哀鸣。
- **无风之海**：风力和声音彻底消失的绝望水域，驶入其中的船只皆化为死寂幽灵。

## 四、演化八线（世界独立推进引擎）

**战争 · 王位更替 · 教会分裂 · 学院新论 · 魔法技术 · 魔兽迁徙 · 魔族动向 · 商路兴衰**——独立演算，不等玩家。

| 演化线 | 阶段推进刻度 |
|---|---|
| **战争** | 边境摩擦 → 全面动员 → 正式开战 → 胶着相持 → 终战（胜/和/溃败）→ 战后余波 |
| **王位更替** | 老王衰颓 → 继承纷争浮出水面 → 宫廷摊牌 → 大局已定 → 新王清洗异己 |
| **教会分裂** | 派系暗斗 → 教义争端公开化 → 决裂/立伪宗 → 成立武装圣军 或 妥协媾和 |
| **学院新论** | 私下密传 → 论文公开震撼学界 → 学派大论战 → 列为异端被禁 或 编入正统正典 |
| **魔法技术** | 理论雏形 → 密室试验验证 → 小范围定制应用 → 商业化普及 → 颠覆旧行业（招致反扑） |
| **魔兽迁徙** | 异变目击 → 局部兽灾爆发 → 跨区域大迁徙 → 建立新领地生态 或 被联合剿灭 |
| **魔族动向** | 零星斥候渗透 → 暗桩势力布局 → 挑起边境事端 → 与周边人类割据势力媾和或开战 |
| **商路兴衰** | 谣言风声 → 商队谨慎改道 → 建立新兴商路 → 贸易集市繁盛 → 被战火/劫匪扼杀 |
